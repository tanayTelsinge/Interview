# Angular Learning Roadmap

## Order to follow:
1. **01_basics** → What is Angular, CLI setup, project structure
2. **02_components** → Component lifecycle, @Input/@Output, ViewChild
3. **03_data_binding** → Interpolation, property, event, two-way binding
4. **04_directives** → *ngIf, *ngFor, ngClass, ngStyle, custom directives
5. **05_services_DI** → Services, Dependency Injection, Singleton
6. **06_routing** → RouterModule, route params, guards, lazy loading
7. **07_forms** → Template-driven vs Reactive forms, validation
8. **08_http** → HttpClient, interceptors, error handling
9. **09_pipes** → Built-in pipes, custom pipes, async pipe
10. **10_state_management** → NgRx (store, actions, reducers, effects, selectors)
