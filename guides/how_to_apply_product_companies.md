## 2. Application Channels (Ranked by Effectiveness)

### Channel 1: Employee Referral — HIGHEST success rate
- A referral moves your resume to the top of the queue and bypasses ATS.
- How to get one:
  1. Search the target company on LinkedIn → filter by "1st/2nd connections".
  2. Message directly: _"Hi [Name], I'm a Java backend engineer with X years of experience. I'm applying for [Role] at [Company]. Would you be open to referring me? Happy to share my resume."_
  3. Don't ask strangers cold — warm up first: like/comment on their posts, engage on a shared topic.
  4. Alumni networks (college batch WhatsApp/Telegram groups) are underrated — use them.

### Channel 2: LinkedIn Easy Apply / Direct Career Page
- Apply directly on the company's careers page (better tracking than LinkedIn).
- Set LinkedIn to "Open to Work" (visible to recruiters only — not public).
- Optimize LinkedIn headline: `Java Backend Engineer | Spring Boot | Distributed Systems | Open to SDE-2/3 roles`

### Channel 3: Recruiter Outreach (Cold)
- Find in-house recruiters on LinkedIn (search: `[Company] recruiter java backend`).
- Short message: _"Hi [Name], I came across the [Role] opening at [Company]. I have X years in Java/Spring Boot with experience in [relevant domain]. Could you let me know the best way to apply or if there's a fit?"_

### Channel 4: Job Aggregators
- [LinkedIn Jobs](https://linkedin.com/jobs)
- [Naukri.com](https://naukri.com) — most effective for Indian companies
- [iimjobs.com](https://iimjobs.com) — product/startup roles
- [cutshort.io](https://cutshort.io) — startup-friendly, skills-based matching
- [instahyre.com](https://instahyre.com) — product company focus
- [wellfound.com](https://wellfound.com) (AngelList) — startups

## 3. Resume: What Product Companies Actually Screen For

### Must-Haves
- **Impact-driven bullets**: _"Reduced API latency by 40% by introducing Redis caching, cutting DB load by 60%"_ — not _"Worked on backend APIs"_.
- **Scale signals**: mention QPS, data volume, user count where applicable.
- **Tech stack visible upfront**: Java, Spring Boot, Kafka, Redis, PostgreSQL, Kubernetes — put these in a skills section AND weave into bullets.
- **STAR-lite format per bullet**: Action + Method + Result.
- 1–2 pages max. Senior engineers: 2 pages acceptable.

### What to Drop
- Objective statements ("Seeking a challenging role…")
- Responsibilities without outcomes
- Skills you'd fail a quiz on (don't list Kubernetes if you only ran `kubectl get pods`)
- Outdated tech (J2EE, Struts, EJB) unless the JD asks for it

### ATS Keywords (Java backend roles)
Tailor to each JD. Common keywords:
`Spring Boot`, `Microservices`, `REST APIs`, `Kafka`, `Redis`, `Docker`, `Kubernetes`, `AWS/GCP/Azure`, `PostgreSQL`, `MySQL`, `System Design`, `CI/CD`, `JUnit`, `Distributed Systems`, `High Availability`

### Resume Tools
- [Resume.io](https://resume.io) or [Overleaf](https://overleaf.com) (LaTeX) — clean ATS-friendly formats
- [Jobscan.co](https://jobscan.co) — check ATS keyword match against JD

## 4. Interview Process by Company Type

### FAANG / Google / Amazon / Meta
| Round | What's Tested |
|---|---|
| Online Assessment (OA) | 2 LeetCode Medium/Hard problems, 60–90 min |
| Phone Screen | 1 DSA problem (medium), basic resume questions |
| Virtual Onsite (4–5 rounds) | 2× DSA, 1× System Design (HLD), 1× LLD (OOD), 1× Behavioral |
| Bar Raiser (Amazon) | Leadership Principles deep-dive |

**Amazon LP Questions** — prepare 2 stories per principle for the 14 LPs. Most tested:
- Ownership, Bias for Action, Deliver Results, Customer Obsession, Dive Deep.

### Indian Unicorns (Flipkart / Swiggy / Razorpay / Zepto)
| Round | What's Tested |
|---|---|
| Resume shortlist / HackerEarth OA | DSA (2–3 problems, medium level) |
| Machine Coding Round | 90–120 min: fully working Java solution, runnable with test inputs |
| HLD Round | Design a real system (e.g., food delivery, notification service) |
| Engineering Manager Round | Project deep-dive, ownership, conflict resolution |
| HR Round | Compensation, joining timeline |

**Key difference**: Indian unicorns care more about **working code** than class diagrams. You must produce compilable, runnable Java in the machine coding round.

## 5. Timeline: 12-Week Application Sprint

### Weeks 1–4: Build the Foundation
- [ ] Update resume with impact bullets
- [ ] Optimize LinkedIn profile
- [ ] Solve 50 LeetCode mediums (focus: arrays, strings, trees, graphs, DP)
- [ ] Study System Design basics (caching, load balancing, DB design)

### Weeks 5–8: Interview Prep Intensifies
- [ ] Solve 30 more LeetCode problems (medium-hard)
- [ ] Practice 5+ LLD machine coding problems (Parking Lot → BookMyShow → Splitwise)
- [ ] Prepare 10 STAR behavioral stories
- [ ] Start applying — 5–10 applications/week
- [ ] Request 3–5 referrals from network

### Weeks 9–12: Mock Interviews + Active Pipeline
- [ ] Do 4+ mock interviews (Pramp, interviewing.io, Preplaced.in)
- [ ] Apply to remaining target companies
- [ ] Follow up on applications after 7–10 days
- [ ] Negotiate offers — always wait for written offer before negotiating

## 6. Following Up After Applying

- **Wait time**: 1–2 weeks before following up.
- **Who to contact**: the recruiter on LinkedIn or via careers portal message.
- **Template**:
  > _Hi [Name], I applied for [Role] at [Company] on [Date] (Application ID if available). I'm very interested in this role given [specific reason]. Could you let me know if my profile is under review? Happy to provide any additional information._
- Don't follow up more than twice — move on if no response after 2 attempts.

---

## 7. Offer Negotiation Basics

1. **Never reveal your current CTC first** — deflect: _"I'm looking at market rate for this role and level. What's the band?"_
2. **Always negotiate** — first offers are rarely final. A polite counter is expected.
3. **Negotiate the full package**: base salary + ESOPs/RSUs + joining bonus + variable pay + designation.
4. **Counter template**: _"I'm very excited about this opportunity. Based on my research and competing offers, I was hoping we could get to [X]. Is there flexibility on the base or equity component?"_
5. **Competing offers are your strongest leverage** — time them if possible.
6. Indian unicorns: push hard on ESOPs (can be 3–10x base over 4 years at growth-stage cos).

## 9. Red Flags to Watch Out For

- JD asks for 10+ years for an SDE-2 role — unrealistic bar, skip or negotiate title.
- No clear interview process communicated upfront — ask before starting rounds.
- Recruiter pressures you to accept before competing offers expire — it's a tactic; don't panic.
- Company has >40% negative reviews on Glassdoor/Blind for engineering culture — do due diligence.
- Offer letter significantly different from verbal offer — get everything in writing.
