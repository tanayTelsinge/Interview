🎬 Netflix System Architecture

~200M users · 190+ countries · Billions of events/day · Runs on AWS
① Client Layer
Smart TVs / Consoles
Native apps, adaptive streaming SDK embedded in 1000+ device types
Mobile (iOS / Android)
Offline downloads, React Native UI, adaptive bitrate
Web Browser
React frontend, EME API for DRM playback
Netflix SDK
Shipped inside devices at factory. Controls playback, auth, QoE reporting
↓ All requests
② CDN & Edge — Open Connect Netflix Custom
Open Connect Appliances
Physical servers Netflix places inside ISPs globally. Serve 95%+ of video — data never leaves the ISP network
DASH / HLS Adaptive Bitrate
Switches video quality every few seconds based on real-time bandwidth. Seamless for viewer
AWS CloudFront (fallback)
API responses, images, metadata. Video always goes through Open Connect
↓ Non-video API traffic
③ API Gateway & Load Balancing
Zuul Netflix OSS
Edge gateway — routing, auth token validation, rate limiting, A/B experiment injection on every request
AWS ELB
Distributes traffic across AZs. Auto scales with demand spikes (Friday night rush)
Ribbon Netflix OSS
Client-side load balancing between microservices. Works with Eureka for service discovery
↓ Routed to services
④ Core Microservices — 500+ Services on AWS ECS / EC2
User Service
Auth, profiles, preferences, subscription tier, parental controls
Catalog Service
Content metadata, titles, genres, regional availability, artwork
Playback Service
Stream URL generation, DRM license, device capability negotiation
Recommendation Service
ML models serve personalized rows. Different model per surface (home, search, similar titles)
Search Service
Elasticsearch-powered. Multilingual, typo-tolerant, personalized ranking
Billing Service
Subscription management, payment processing, dunning, invoicing
Notification Service
Email, push, in-app alerts. Async — consumes from Kafka, never blocks user flow
A/B Test Service
1000s of concurrent experiments — UI, algorithm, thumbnail, audio quality tests
↓ Events published to bus
⑤ Async Messaging — Apache Kafka
Apache Kafka OSS
Central event backbone. Trillions of events/day. Decouples all services — producers don't know consumers
Play Events
Every second of video watched → Kafka → analytics. Powers "continue watching" + recommendation signals
User Activity Events
Search, browse, thumbs up/down, pause → feeds ML model training pipelines
QoE / Error Events
Rebuffering, startup time, errors → real-time alerting, ISP performance dashboards
↓ Consumed by data, cache & processing layers
⑥ Data Stores
MySQL (AWS RDS)
Billing, user accounts — ACID transactions
Apache Cassandra
Viewing history, activity — high write throughput, no SPOF, multi-region
AWS S3
Raw video masters, encoded assets, data lake for all analytics
Elasticsearch
Search index + log aggregation across all services
⑦ Caching
EVCache Netflix Custom
Memcached wrapper. 30M+ req/sec. Multi-region replicated. Catalog & homepage rows cached here
Redis
Sessions, rate limiting counters, leaderboards, pub/sub
Local In-Process Cache
Each microservice caches hot data in-memory. First line before EVCache
⑧ Big Data Processing
Apache Spark
Batch — recommendation model training, content analytics, business reports on S3 data lake
Apache Flink
Real-time stream processing — live QoE metrics, fraud detection, trending content
Hive / Apache Iceberg
SQL warehouse on S3. Iceberg handles table versioning and time-travel queries
↓
⑨ Resiliency
Hystrix Netflix OSS
Circuit breaker — if a service degrades, opens circuit and returns fallback. Stops cascade failures
Chaos Monkey Netflix OSS
Randomly kills prod instances during business hours. Forces every team to build resilient services by default
Multi-Region Active-Active
Runs in us-east-1, us-west-2, eu-west-1 simultaneously. Regional failover in minutes
⑩ Observability
Atlas Netflix Custom
In-memory time-series metrics platform. Billions of metrics/day. Powers all dashboards and alerts
Distributed Tracing (Zipkin)
Traces a single request across 500+ microservices. Essential for debugging latency issues
Mantis
Real-time stream processing for operational data. Live tail of production events
↓ Content pipeline (offline)
⑪ Video Encoding Pipeline (Offline Batch)
Raw Upload → S3
Studio delivers raw 4K/8K masters. Stored in S3 as permanent source of truth
Encoding Farm (EC2 Spot)
1000s of spot instances encode each title into 1000s of bitrate + resolution + codec variants
Per-Title Encoding (ML)
ML analyzes each scene — action gets higher bitrate, static scenes lower. ~50% bandwidth saving
Push to Open Connect
Encoded chunks replicated to CDN appliances inside ISPs before title goes live
